# 目标配置说明

公开版本不包含任何个人路径、课程页面 ID、账号凭据或课件。首次使用时，请用户提供以下信息；缺少写入目标时，先完成不受影响的只读检查，不猜测目标。

## 必需目标

- 学校的 Canvas 网址，以及本次要同步的学期。
- 已在本机同步的 OneDrive 学期根目录（绝对路径）。
- Notion 学期父页链接；访问后核对页面身份。

## 可选参考

- 已有课程编号、课程目录与 Notion 课程父页的对应关系。该表仅用于匹配，不能作为选课白名单。
- 已有同课程 lecture 笔记或历史学期笔记，用于参照命名、层级、详细程度和图文排版。

用户希望复用目标时，可在本机创建 `references/personal-targets.md` 保存上述映射，并记录配置对应的学期。该文件已被 Git 忽略，不应提交到公开仓库。不要在配置中保存密码、访问令牌、cookies 或临时签名下载链接。

学期变化时重新核对目标；未列出的当前课程仍需发现。课程目录保留现有结构，新分类直接放在课程目录下，不加“课件”层。课程研究论文不因位于学期目录就自动视为 lecture。
